# Aura 横屏当前天气标题区设计

## 目标

重新排列 `320 x 240` 横屏首页顶部，让当前温度和天气状态占据原有地点、网络状态和天气源名称的空间。竖屏首页、天气数据源设置、天气请求流程和横屏预报图表不在本次调整范围内。

用户已选择 A「温度主导」方案。

本文档覆盖 `2026-08-22-landscape-weather-ui-design.md` 中“Landscape Home Layout”关于横屏标题区的描述；其余图表、主题、旋转和设置设计继续有效。

## 信息层级

横屏顶部按以下优先级展示：

1. 当前温度，使用 42px 字体，是顶部最醒目的信息。
2. 当前天气状态，使用 20px 字体并采用主题强调色。
3. 当日日出、日落和最近更新时间，使用 12px 字体与弱化色，在同一行平铺。
4. 七天/逐小时切换和设置按钮保持现有视觉权重。

横屏首页不再显示地点名称、设备 IP 或天气源名称。`Shenzhen`、`Open-Meteo`、`QWeather` 等内容都不会出现在横屏首页，但相关信息和设置继续保留在竖屏或设置界面中。

## 布局

顶部区域维持现有 `0-58px` 高度，图表仍从 `y = 62` 开始。

- 当前温度位于左上角，边界为 `x = 6, y = 0, w = 76, h = 46`。
- 当前天气状态位于温度右侧，边界为 `x = 84, y = 4, w = 96, h = 24`。
- 日出时间位于标题区底行，边界为 `x = 6, y = 44, w = 94, h = 13`。
- 日落时间与日出保持水平，边界为 `x = 104, y = 44, w = 88, h = 13`。
- 更新时间与日出、日落保持水平，边界为 `x = 196, y = 44, w = 118, h = 13`。
- 七天/逐小时按钮继续使用 `x = 188-282, y = 2-27`。
- 设置按钮继续使用 `x = 284, y = 2, w = 30, h = 25`。

天气状态应使用单行省略模式，确保较长翻译不会侵入右侧控制区。底行依次显示 `日出 06:15`、`日落 18:42` 和 `更新时间 22:30`，不带日期或数据源名称。体感温度和湿度不在横屏首页显示。

## 视觉规则

- 当前温度使用主题正文色，度数符号使用主题高温色。
- 当前天气状态使用主题强调色。
- 日出、日落和更新时间使用主题弱化色。
- 不增加顶部卡片、边框或背景块，保持现有沉浸式图表风格。
- 不增加当前天气大图标，避免与大温度争夺空间。
- 图表、七列日期、预报图标和预报天气描述的尺寸与位置保持不变。

## 数据与状态

天气快照新增当天日出、日落的 `HH:mm` 值及各自有效标志。Open-Meteo 请求在现有 daily 字段中加入 `sunrise,sunset`，读取第一个日期的值；和风天气从现有七日预报响应的 `daily[0].sunrise` 和 `daily[0].sunset` 读取。时间解析只接受可提取为 `HH:mm` 的值，不新增网络请求。

横屏更新时间不依赖天气源名称。天气源切换、自动回退和重新获取天气后，只刷新显示时间及当前天气数据。

日出或日落字段缺失、格式无效时，只将对应一项显示为 `--:--`，不能令整次天气快照失败或触发数据源回退。天气快照发布后，横屏当前天气和三项时间在同一次渲染中更新。

缺失数据时：

- 温度显示现有温度占位符。
- 天气状态显示 `--`。
- 日出缺失时显示 `日出 --:--`。
- 日落缺失时显示 `日落 --:--`。
- 更新时间缺失时显示 `--`，不重新显示天气源名称。

## 实现边界

本次实现修改天气快照的太阳时间字段、两个天气源的现有响应解析、横屏标题区创建与状态刷新逻辑。竖屏首页继续显示其现有地点、体感温度、湿度、网络状态和天气源信息。设置页中的地点与天气源控件不变。

应复用已内嵌的 42px、20px 和 12px 字体，避免新增字体资源。若非中文语言的天气状态超过可用宽度，使用省略号，不缩小字体或移动右侧按钮。

## 验证

自动化检查应覆盖：

- 横屏标题区不创建或不显示地点、网络状态和天气源名称。
- 横屏温度使用 42px 字体，天气状态使用 20px 字体。
- 横屏更新时间文本不包含 `Open-Meteo` 或 `QWeather`。
- 横屏不创建体感温度标签，并创建日出、日落标签。
- Open-Meteo 与和风天气都将当天日出、日落写入同一快照字段。
- 日出或日落缺失时单项降级为 `--:--`，其余天气快照仍可发布。
- 竖屏状态显示与天气源设置行为保持不变。
- 图表坐标、七列预报坐标、切换按钮和设置按钮保持现有值。

视觉检查应覆盖五套主题、中英文、长天气状态、温度占位符、无太阳时间和无更新时间状态。在 `320 x 240` 画布内，温度、天气状态、日出、日落、更新时间和右侧控制不得重叠。

## 验收标准

- 横屏首页不显示地点名称、设备 IP 或天气源名称。
- 当前温度清晰占据左上主要空间，字号为 42px。
- 当前天气状态字号为 20px，并与温度形成同一视觉组。
- 横屏不显示体感温度和湿度；底行完整显示日出、日落、更新时间并保持水平平铺。
- 图表和底部预报区域不下移、不缩小。
- 七天/逐小时切换和设置按钮的位置与交互不变。
- 竖屏首页和设置页不受影响。
